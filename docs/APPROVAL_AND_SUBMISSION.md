# Coordinator approval and submission checklist

The MMA3001 brief explicitly requires coordinator approval for a self-selected simulation. A simplified one-degree-of-freedom suspension is not automatically approved.

**Suggested message:** I propose simulating vertical free vibration of a linear sprung-mass vehicle suspension using explicit Euler and RK4, verifying against an analytical solution and comparing error, convergence, runtime, stability and damping sensitivity. I will also compare the parameter assumptions with a published MIT teaching example, without claiming experimental validation. Would this be acceptable for the self-selected simulation route, or is a forced/two-degree-of-freedom model required?

## Submission requirements
- [ ] Obtain approval for this exact scope.
- [ ] Run analysis and automated tests locally, review every result.
- [ ] Make a final 5–10 page written report (references and appendices excluded).
- [ ] Include engineering problem, full input/output contracts, solution, alternatives, validation, optimisation, limitations, AI reflection, references.
- [ ] Include documented Python functions, comments, HTML code documentation, tests and test report in GitHub.
- [ ] Include an appropriate licence, README, dependency instructions and genuine version-control commits.
- [ ] Submit written report through Moodle, accessible GitHub link, and zipped clone through Moodle.
- [ ] Deliver a five-minute demonstration followed by three minutes of questions.
- [ ] Complete AI reflection honestly with your own verification, decisions, errors found and learning.

**Five-minute structure:** engineering question (45s), equations and inputs (45s), methods and GitHub (55s), validation and convergence (70s), limitations and sensitivity (45s), AI use and learning (40s).
